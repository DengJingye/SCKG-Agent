# 主聊天的离线评分与检索诊断

状态日期：2026-10-18。原16次调用主结果保留；本页区分事后匹配敏感性与另行冻结的检索机制探针。两者均新增0模型调用，产品默认检索未改。

新离线policy让已返回决策在不同辅助理由长度约束下作敏感性检查。它不重新调用模型，不重新生成答案，不是把原invalid_response改成succeeded。原v1仍是4个有效judge、1个完整配对、4个NA，原有效分数逐字段相同。

## 改了什么、没改什么

只在新的离线policy放开每条辅助reason原160字符的独立上界，仍保留非空字符串、完整提案/参考ID、类型、数量、重复、witness、来源绑定和raw总32,768字节等限制。协议将该放宽绑定为总raw上限下冗余的字符界，不允许无限输出或其他坏结构。全部8份冻结输入统一处理，没有挑失败项或有利项单独救分。

amendment和protocol在新增计算前绑定，但政策是在观察过v1失败之后提出，仍是posthoc；它不是预注册确认试验。原4份invalid_response依旧invalid_response，原v1的4个NA依旧NA；另4份原有效分数完全不变。旧16调用账户保持关闭，既有65,945报告tokens与未知金额不因0API诊断变成新调用或新费用记录。

## 查询与索引的2×2机制探针

普通检索实际在全问题前40个正则词处截断；既有单列索引包含抽取主张及条件、未知等字段，未包含原英文引文。本轮分别检验两个因素，使用相同220个当前用途可用单元和全部历史FTS行，不增加内容或提升候选权限：

- Q0为旧前40词；Q1为全问题去重后均匀选择至多40个原词。
- I0为原索引；I1仅对当前可用单元追加全部既有原引文。两索引共用预先固定的查询，两查询共用相同索引。

Q0I0先精确复现四题原KnowledgeService完整包、top5顺序及完整请求体，之后才执行16个cell。13项合成检查通过；实际探针3.0936秒、90,931,200字节采样峰值，原数据及53模块未改。

## 复用与后续验收

对已发表开源系统的窄调研支持三类可复用边界：[BioChatter](https://www.nature.com/articles/s41587-024-02534-3)的schema约束查询，[BioCypher](https://www.nature.com/articles/s41587-023-01848-y)的适配器、身份与来源治理，[OpenScholar](https://www.nature.com/articles/s41586-025-10072-4)的检索、重排及归因分层。迁移先复用本仓已有接口，不引入新的图数据库、向量模型或GPU环境；论文发表不证明本机迁移有效。静态源码的许可和边界研究不等于实际原生agent对照。

新查询资格须绑定完整可见问题、当前release、全部模型请求体、预算和真实回执；超过原规划器容量则停止，不静默截目录。知识补充须保留来源、前提、依赖、未知与执行验收；开发候选不得冒称人审正式知识。同事实表示、更多独立任务和含Genpilot的原生外部比较继续分轨。

四道公开开发题、同一旧模型判断与事后字段政策不能建立确认增益、独立生物学N、领域金标或外部优势。原v1、所有失败与事后结果并列保留；不把这组差值写成简历中的科学准确率提升。
