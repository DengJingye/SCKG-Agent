本材料说明开发知识包的内容与边界。流程候选与本地实验规则分别保存，未获人工审核、正式发布或当前数据适用性资格；候选条数和引文匹配不代表科学增益。公开仓库只提供摘要，不附私人台账、全文归档或查询标签。

## 已补的八类来源内容

| 来源候选 | 必须跟随知识保留的条件与限制 |
| --- | --- |
| CellTypist 训练表达尺度 | 除原始计数表的文件路径输入外，作者要求 log1p、每细胞归一到 10,000；关闭格式检查仅绕过检查。 |
| 稀疏输入内存选择 | `with_mean=False` 可减少内存，作者同时说明可能影响表现；没有测得本项目的收益幅度。 |
| 监督特征选择 | 两次训练、每类按回归系数绝对值选基因再取并集，训练时间增加；具体折内拟合规则另属实验协议。 |
| 稀有类别重采样 | `balance_cell_type` 仅对 `use_SGD=True` 且 `mini_batch=True` 有关；不能套到冻结的 `mini_batch=False` 配置。 |
| 参考适配 | 标注质量、分辨率、噪声及训练数据与查询的技术差异会影响注释；没有证明当前参考覆盖所有查询类型。 |
| 注释诊断 | 作者教程建议结合替代注释、marker 和人工检查；低置信提示需检查，没有通用数值阈值或已完成专家审核。 |
| 训练输入错误 | 1.7.1 源码对标签长度、基因轴和表达格式条件报错；所引格式条件检查首行，不能当作全矩阵验证。 |
| 特征数量错误 | 1.7.1 特征选择分支在 `len(genes) <= top_genes` 时拒绝；此轴已经过滤零表达基因，不能用原始基因数代替。 |

前四条来自[作者训练文档](https://celltypist.readthedocs.io/en/latest/celltypist.train.html)，参考适配和诊断来自 [Best Practices 注释章节](https://www.sc-best-practices.org/cellular-structure/annotation/)，两个错误条件来自 [CellTypist 1.7.1 源码](https://github.com/Teichlab/celltypist/blob/1.7.1/celltypist/train.py)。开发记录冻结实际归档字节 SHA；`latest` 文档快照与固定 1.7.1 源码是不同修订，不能混成同一版本。

## 实验规则单独保存

本地胰腺实验的固定数据轴、参考内 80/20 划分及 seed、最多两个候选、允许参数网格、macro-F1 选择、最终参考拟合、完整预测 ID、预算及完成/产物/科学评分分离，共七组规则。这些是研究者制定的比较协议，不能写成论文作者的结论，也不能用查询标签选择方法或参数。

## 下一项验收

知识单元需保持原件、修订、精确跨度、条件、属性证据和未知项。当前训练和诊断段落不足以建立 CellTypist 预测概率、行和、校准或类别权重优越性；这些保持未知，随后仅补对应版本的预测实现或作者说明。

开发包使用实际准备输入后另行提交的抽取结果，校验输入哈希和逐块交代，再执行候选导入与幂等复验。大片源码只摘取失败分支时标为 partial，不将 linked 当作语义完整率。独立开发 AI 复核属于开发审查，不能充当人工科学金标。

后续先检验条件能否传递到方法选择和输入检查，再做同任务、同生成器、同预算的知识消融；生产推荐、科学效用和外部 agent 优势分别验收。
